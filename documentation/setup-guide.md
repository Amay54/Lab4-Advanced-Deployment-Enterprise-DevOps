# Setup Guide - Lab 4

## Prerequisites
- **Git** (version 2.30+)
- **Python** (version 3.10+)
- **Docker & Docker Compose** (for containerized deployments)
- **Kubectl** (for Kubernetes manifests)

## Local Installation
Clone the repository:
```bash
git clone https://github.com/Amay54/Lab4-Advanced-Deployment-Enterprise-DevOps.git
cd Lab4-Advanced-Deployment-Enterprise-DevOps
```

Install Python testing dependencies:
```bash
pip install -r question-2-automated-testing/app/requirements.txt
pip install pytest pytest-cov
```
